# ניהול משתמשים – פרויקט Android (Java)

אפליקציה עם 4 מסכים: כניסה ראשית, רישום, התחברות ורשימת הנרשמים.
מסכי הרישום וההתחברות בנויים כ־**Fragments** בתוך Activity אחד, ורשימת המשתמשים נשמרת ב־**ArrayList**
(וגם בבסיס נתונים SQLite כדי שהרשימה תישמר אחרי סגירת האפליקציה).

## חשוב לפני הגשה
בקובץ `app/src/main/res/values/strings.xml` החליפו את:
* `student_name` – השם הפרטי ושם המשפחה שלכם.
* `student_id` – מספר תעודת הזהות שלכם.

## המסכים
| מסך | קובץ | מה יש בו |
|-----|------|-----------|
| 1. מסך ראשי | `MainActivity` + `activity_main.xml` | תמונה, שם התלמיד ות.ז, ברכה וכפתור "המשך לדף הבא" |
| 2. רישום | `RegisterFragment` + `fragment_register.xml` | שם משתמש (עם מונה 30 תווים), אימייל, סיסמה ואישור סיסמה + כפתור "רישום" |
| 3. התחברות | `LoginFragment` + `fragment_login.xml` | אימייל וסיסמה + כפתור "כניסה" |
| 4. רשימת הנרשמים | `UsersActivity` + `activity_users.xml` | פרטי המשתמש שהתחבר וכל המשתמשים הרשומים (שם + אימייל) |

## מבנה הקוד
* `AuthActivity` – Activity שמארח את שני ה־Fragments בתוך `ViewPager2`, כך שאפשר גם ללחוץ על הטאבים וגם להחליק (swipe) בין מסך הרישום למסך הכניסה.
* `SystemBars` – מוסיף את גובה שורת הסטטוס, המצלמה הקדמית ופס הניווט כשוליים, כדי ששום טקסט לא ייחתך בחלק העליון.
* `User` – מחלקת המודל: שם, אימייל וסיסמה.
* `UserStore` – ניהול המשתמשים ב־ArrayList: `load`, `add`, `findByEmail`, `remove`.
* `DatabaseHelper` – SQLite: יצירת טבלה, הוספה, שליפה ומחיקה של משתמש.
* `UsersAdapter` – מציג שורה אחת ברשימה (שם + אימייל).

## ולידציה והודעות
* כל השדות חובה.
* האימייל נבדק בפורמט תקין (`Patterns.EMAIL_ADDRESS`).
* הסיסמה לפחות 6 תווים, ואישור הסיסמה חייב להיות זהה.
* אימייל שכבר קיים במערכת לא ניתן לרשום פעמיים.
* בכניסה: אם המשתמש לא קיים או הסיסמה שגויה – מוצגת הודעה מתאימה מתחת לשדה.

## תוספת אישית
* עין להצגת/הסתרת הסיסמה בכל שדות הסיסמה.
* לחיצה ארוכה על משתמש ברשימה מוחקת אותו (עם חלון אישור).
* הברכה במסך הראשי מתעדכנת לשם המשתמש שהתחבר.
* ממשק בעברית עם כיוון RTL וצבעים, ומעבר חלק (החלקה) בין מסכי הרישום וההתחברות.

## הרצה
פתחו את הפרויקט ב־Android Studio והריצו, או מהטרמינל:

```bash
./gradlew :app:assembleDebug
```
